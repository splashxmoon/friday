# Security

Friday runs on your own computer, listens on `127.0.0.1` only, and drives coding tools that can change files and run commands. We take reports about it seriously.

## Reporting a problem

Please don't put the details in a public issue. Email **security@tryfridaywork.com** with what you found and how to reproduce it. We'll answer within three working days and keep you posted until it's fixed.

## What counts

- Anything that lets a web page, a previewed site or another computer reach Friday's server or act as its page.
- A way around the permission a coding tool was given (Plan, Ask, Edits, Auto).
- Secrets from your computer ending up somewhere they shouldn't.

## Supported versions

The latest release. Fixes ship in a new release and the desktop app tells you when one is out.
